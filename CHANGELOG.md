# Changelog

## 0.01

- Initial independent Cinder Ash theme using the approved nine-color palette.
- Added Plasma style, KDE palette, Kvantum style, Aurorae decorations, wallpaper and startup splash.
- Integrated lock-screen wallpaper and complementary colors with KDE’s native authentication interface.
- Added responsive SDDM login UI with user/session selection, password entry, keyboard layout display, power controls and About information.
- Added separate desktop and SDDM installers with backups and conservative rollback.
- Preserved icon, cursor, font and desktop-layout preferences.
